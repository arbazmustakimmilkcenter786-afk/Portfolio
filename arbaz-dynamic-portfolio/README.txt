## Premium interaction enhancements
This version preserves the existing glass hero, typography, color palette, sections and project content while adding:

- cinematic scroll reveals and progressive section entrance
- scroll progress indicator and active navigation state
- sticky navigation choreography after scrolling
- lightweight initial loading transition
- custom cursor with hover labels on desktop
- subtle magnetic buttons and hover feedback
- project-card tilt, shine, preview depth and cursor-following lighting
- timeline progress drawing and staggered content reveals
- animated skill bars and smoother skill-panel transitions
- polished contact-form focus and status transitions
- refined modal transitions and back-to-top interaction
- mobile-safe fallbacks and `prefers-reduced-motion` support

No framework or animation library was added; the interactions use CSS transforms, IntersectionObserver and requestAnimationFrame where appropriate.
